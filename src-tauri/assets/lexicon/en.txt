# Cadence unparliamentary-language lexicon — English
#
# Format, one term per line:
#
#   term | category | severity
#
# category: profanity | slur | sexual | violent | insult
# severity: mild | strong | severe
#
# An allowlist entry starts with "!" and suppresses a match whose surrounding
# word equals it. This is what stops the Scunthorpe problem: a term that is a
# substring of an innocent word.
#
#   !assessment
#
# Blank lines and lines starting with "#" are ignored. Terms are normalised
# the same way transcript text is (lowercased, leetspeak folded, repeated
# characters collapsed), so there is no point listing "sh1t" or "shiiit"
# separately — write the plain form once.
#
# This file is compiled into the binary. To add terms for one organisation
# without rebuilding, put a file of the same format at
#
#   %APPDATA%\com.cadence.app\lexicon\en.txt
#
# and it will be merged over this one at load time. An override entry for a
# term already listed here replaces its category and severity.
#
# --------------------------------------------------------------------------
#
# WHAT IS DELIBERATELY NOT HERE: slurs. This file ships in a public source
# repository, and a list of racial, religious, caste, sexual-orientation or
# disability slurs does not belong in one. The `slur` category exists and is
# handled throughout the pipeline; populating it is left to the deploying
# organisation, through the override file above. That is also the right place
# for it on the merits — which words an organisation treats as unrepeatable in
# a circulated record is its own policy, not this project's.
